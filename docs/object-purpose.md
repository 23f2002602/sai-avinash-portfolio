# Purposeful object motion

The approved photo hero and first character story are unchanged.

Interest artwork is now a navigation instrument: selecting a tool activates its own visual behavior, transmits a signal along its connection to the dial, updates the readable detail, and offers a relevant existing chapter link. Previous/next frequency controls work on touch and keyboard. Unselected tools no longer float continuously. Camera shutter, video pan, drawing/build strokes, cooking steam, globe movement, and balance are visual cues, not claims of interactive 3D models.

Headphones have a visual-only focus toggle that changes their pose, waveform rhythm, and focus caption. No audio is requested or played.

Coffee retains its six persistent crossfading frames. Brew, milk, and stir reuse the existing high-quality raster in layered SVG clips: cup stays still while kettle/pitcher/spoon move independently. Liquid flow, surface rhythm, falling beans, grinder movement, and steam give each stage an action. Stage-specific replay controls restart these actions rather than pulsing the entire image.

All loops pause offscreen and in hidden tabs. The motion toggle and system reduced-motion preference stop action animations without removing content or navigation. Existing artwork files and character interfaces are preserved; no generation or credentials are needed.
